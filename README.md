# YAMLSED

**YAML template matching & processing.**

Yamlsed keeps YAML templates up to date. Point it at a **base** template and a
**patch**, and it applies the patch's changes wherever the base matches —
declaratively and version-controllably, instead of hand-editing the file.

```bash
pip install yamlsed
```

**[Documentation](https://victormpa.github.io/yamlsed/)** — concepts, matching, patching, and examples.

Early / work in progress. Syntax may change.
